# Project Notes

## Project
Sales Forecasting & Analysis

## Purpose
Analyze historical sales performance and prepare a practical forecasting workflow using Excel, SQL, and Power BI.

## Dataset
Synthetic portfolio dataset covering January 2023 to December 2025 across:
- Electronics
- Furniture
- Office Supplies
- North, South, East, and West regions

## Forecasting Approach
The Excel workbook includes a 3-month moving-average forecast. This provides a transparent and easy-to-explain baseline for a fresher Data Analyst portfolio project.

## Interview Talking Points
- Explain how the raw data was checked and formatted.
- Explain monthly aggregation and category/region analysis.
- Explain SQL GROUP BY and date-based analysis.
- Explain why a moving-average forecast was used as a simple baseline.
- Explain how Power BI can turn the analysis into an interactive dashboard.
